# 📰 Hamro News

Hamro News is a personalized news aggregation application built with **FastAPI**, **Sqlite**, and **Cohere embeddings**.  
It allows users to receive curated news based on their preferences and leverages AI to filter articles.

---

## 🚀 Features

- 📌 User registration and preference management
- 🗂 Categorized news (sports, politics, technology, etc.)
- 🔍 AI-powered news filtering with Cohere embeddings
- ⚡ FastAPI backend with modular structure (schemas, models, database, routes)
- 🗄 Sqlite database integration


---




## ⚙️ Installation

 Initialize Locally:
   ```
    bash
    git clone https://github.com/princelab0/Hamro_News.git/
    
    cd Hamro_News


    python3 -m venv venv
    source venv/bin/activate   # On Linux/Mac
    venv\Scripts\activate      # On Windows
    pip install -r requirements.txt

    Python main.py
```
