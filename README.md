# News Portal - Frontend

A modern, responsive React TypeScript frontend for Naya-Khabar in both English and Nepali languages. Built with a clean, user-friendly interface and real-time sorting capabilities.



## 🚀 Features

- **🌐 Multi-language Support**: Switch between English and Nepali news
- **📅 Smart Sorting**: Sort news by latest or oldest first
- **📱 Responsive Design**: Optimized for desktop, tablet, and mobile
- **🎨 Modern UI**: Clean, intuitive interface with smooth animations
- **⚡ TypeScript**: Full type safety and better developer experience
- **🔍 Detailed Views**: Click any news card to see full details
- **📊 Real-time Updates**: Instant sorting and filtering

## 🛠️ Tech Stack

- **Frontend Framework**: React 18 with TypeScript
- **Styling**: Pure CSS with modern flexbox/grid layouts
- **State Management**: React Hooks (useState, useEffect)
- **HTTP Client**: Axios for API communication
- **Build Tool**: Create React App
- **Deployment**: Vercel
